작업 도구 담당사람마다 고른 GitHub, Jira, Notion, Slack에서 할 일을 보고 만듭니다. 만들기 전에 비슷한 일이 있었는지 찾아 보여 줍니다쓸 수 있음
통역 담당개발 진행을 쉬운 말로 바꿔 #진행 채널과 팀원들의 도구에 남깁니다쓸 수 있음
파일 정리기내 PC 폴더를 정리하고, 문서와 캡처 속 글자로 파일을 찾습니다쓸 수 있음
접수 담당요청에서 빠진 기기, 재현 방법, 빈도를 두 가지까지만 되묻고 이슈 초안을 만듭니다쓸 수 있음

구조는 셋, 직원은 파일 하나

앱은 화면만 맡고, 일은 내 PC의 호스트가 합니다. 모델은 팀이 정한 서버에서 돕니다.

데스크톱 앱Flutter, Windows
호스트내 PC의 FastAPI. 매니저, 직원, 승인, 기록, OCR
모델 서버vLLM, Qwen3-VL-8B
작업 도구GitHub, Jira, Notion, Slack

직원 추가하기

폴더 하나에 함수 몇 개를 쓰면 직원이 됩니다. 함수 설명이 곧 매니저가 읽는 사용법이고, 쓰는 일은 requires_approval=True 하나로 승인 카드가 붙습니다.

팀 기록이 밖으로 나가지 않게

회사 안에서 쓰려면 무엇이 어디로 가는지 분명해야 합니다. AI Agency는 처음부터 그렇게 나눴습니다.

대화는 팀이 정한 서버에서
모델은 팀 GPU 서버의 vLLM에서 돕니다. 외부 AI 서비스로 대화를 보내지 않아도 됩니다.
캡처 속 글자는 PC 안에서
붙인 이미지는 내 PC에서 OCR로 읽습니다. 파일이 서버로 올라가지 않습니다.
쓰기는 모두 승인한 뒤에
이슈 만들기, 진행 보고처럼 남는 일은 승인 카드에서 사람이 확인해야 실행됩니다.
토큰은 호스트에만
GitHub, Jira 같은 도구의 토큰은 호스트 설정 파일에만 두고 화면과 기록에 내보내지 않습니다.

팀 단위로 시험해 보고 싶다면 도입 문의를 남겨 주세요.
